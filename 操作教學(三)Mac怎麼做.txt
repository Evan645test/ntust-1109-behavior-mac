操作教學(三) 在 Mac 上怎麼做

講義是「04.操作教學(三)__2026-11-06A_1講義.pdf」。
下面照講義頁碼寫。Windows 要裝 GSEQ、開 MPS.exe 的地方，改做右邊這件事。
RPG Maker MV 的遊戲專案在 Mac 上照常打開，記錄腳本不用改路徑。

開始前
1. 解壓縮「臺科1109行為分析-Mac版.zip」。
2. 進「Mac可用」，連按兩下「啟動.command」。
   若被擋住：按住 Control 再點，選「打開」。
3. 終端機留著，做到轉換和分析時再用。


第 12 頁　資料說明
講義要先安裝 GSEQ，並確認 MPS.exe 開得起來。
Mac 不做這兩件事。GSEQ 5.1 和 MPS.exe 是 Windows 程式。
分析改由「啟動.command」完成。


第 13–16 頁　讓遊戲寫下 save.txt
這一段 Mac 和 Windows 相同，只有新建文字檔的方法不同。

1. 用 RPG Maker MV 打開你的遊戲專案。
2. 選單「遊戲」→「開啟專案資料夾」。
3. 打開裡面的 data。
4. 打開「文字編輯」，選「格式」→「製作純文字」。
5. 存成 data 資料夾裡的 save.txt。
   檔名就是 save.txt。不要存成 save.txt.rtf，也不要存成「格式化文字」。
6. 在會發生行為的事件裡，貼上講義第 13 頁的腳本。
   「記錄內容」四個字改成你要記的代碼，引號用英文直引號 " 。
   例：學生點到 NPC，記錄內容寫 A
       學生打開教材，寫 B
       學生作答，寫 C
       答對寫 D，答錯寫 E，再看一次教材寫 F
7. 玩一次測試遊戲。玩完回到 data，打開 save.txt。
   每一行應長得像：A/11/9 18:45:12
   代碼在最前面，後面是日期和時間。這是腳本自己加上去的。

第 17 頁的作業：15 分鐘內做出 10 筆紀錄。
玩完數 save.txt 的行數，至少 10 行。編碼只用這一張表：

  A  與 NPC 互動
  B  閱讀學習教材
  C  回答問題
  D  問題答對
  E  問題答錯
  F  複習學習教材


第 30–32 頁　MPS 把 save.txt 轉成序列
講義的做法：把 save.txt 放到 MPS.exe 旁邊，執行後輸入 n、save.txt、bye，打開 result.txt。
Mac 的做法：

1. 終端機選 1。
2. 把 data 裡的 save.txt 拖進視窗，按 Enter。
3. 結果在 Mac可用/輸出/result.txt，會自動打開。

不用回答 Tiffany，也不用輸入 bye。
result.txt 會像講義第 32 頁：

  % Student #1
   A B C D D E F F ;

每一個大寫字母就是 save.txt 該行的第一個字。小寫開頭的行（sure、cancel、test）不會留下來。
多個存檔就多拖幾個，會依序變成 Student #1、#2。

講義第 33 頁用 Excel 的 =LEFT(A1,1)，是同一件事的手工版。Mac 版已經取好第一個字，不必再在 Numbers 做一次。


第 36–41 頁　做成 GSEQ 的 SDS
講義要在 GSEQ 選 File → New SDS file，貼上這三行，再貼行為，最後 Compile → Compile to MDS file。

  Event
  ($ Behavior = A B C D E F)
  Type (Clinic Control);

Mac 分析時不用編譯，也不會產生 .mds。
若老師要你交出 SDS 文字檔，用「文字編輯」存成純文字，內容是上面三行，接 result.txt 裡的 % Student 段落。
學生和學生之間用分號 ; 。講義最後一位用斜線 / ，Mac 版兩種都認得。
每個代碼中間要有空格。result.txt 已經是這種格式，整段貼上即可。
記事本在 Mac 就是「文字編輯」，記得先改成純文字。


第 42–46 頁　算次數表和調整後殘差
講義在 GSEQ 的點法是：
  Run → Compute table stats
  左邊 givens 放 A B C D E F
  按 change to targets，右邊 targets 也放 A B C D E F
  勾 adjusted residual (z)
  lag 維持 1 to 1
  按執行

Mac 的做法：

1. 終端機選 2。
2. 把 result.txt（或你貼好的 SDS 檔）拖進去。
3. 問代碼範圍時輸入 1，只分析 A–F。這就是講義的六個行為。
4. 瀏覽器會打開 Mac可用/輸出/行為轉換報告.html。

對照講義畫面上的表：
  JNTF、行為關聯出現次數  → 報告裡的「觀察次數」
  ADJR、調整後殘差表      → 報告裡的「調整後殘差 z」
  列 Given 是前一個行為，行 Target 是下一個行為
  講義把 z 大於 1.96 的格子塗成粉紅。報告裡這些格子是橘色，小於 -1.96 是藍色。

同一份數字也在：
  行為轉換報告-次數.csv
  行為轉換報告-z.csv
用 Numbers 打開即可。若作業規定要自己做「大於 1.96」的條件化格式：
選 z 的數字區域 →「格式」→「條件化格式」→「大於」→ 填 1.96。


第 47 頁　畫行為轉換圖
講義是照顯著的 z，把 A 到 F 畫成圓圈，顯著的轉換拉一條線，線上寫 z。
報告裡的「轉換圖」就是這張圖，線上的數字是 z，只畫比期望更常出現的轉換（正的、而且達到 1.96）。
比期望少的藍色格子留在表上，不畫進圖裡，避免線疊在一起。

第 47 頁投影片上的 4.09、3.53、4.51 是講義自己的例圖。
你的圖上的數字來自你自己的 save.txt，不會和例圖逐格相同。
交圖時用報告裡的圖，或照那張圖把橘色的 z 抄到圓圈上。


和講義例圖不要混在一起的地方
素材包裡六位學生的 student1.txt 到 student6.txt，是另一份練習資料，裡面還有 G 和 J。
選單第 3 項會分析這六份。報告另外有一節「只保留 A–G」，其中 D→D 的 z 是 4.09，對得上素材包裡「行為轉換圖.pptx」的 4.09。
那不是第 47 頁例圖的 4.09。自己玩遊戲做出的圖，以你的 result.txt 為準。
