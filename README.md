# 臺科 1109 行為分析（Mac／網頁版）

把 RPG Maker 的 `save.txt` 轉成行為序列，並計算 lag 1 的次數表、調整後殘差和轉換圖。對應課堂上的 MPS.exe 與 GSEQ，可在 Mac 瀏覽器直接使用。

## 網頁版

用瀏覽器打開 `Mac可用/MPS與GSEQ網頁版.html`。

1. 選擇或貼上 `save.txt`，按「轉換」。每一行只留第一個大寫字母。
2. 按「使用上面的轉換結果」。講義的六個行為選「只分析 A–F」，再按「計算」。

檔案只留在自己的電腦，不會上傳。
